## Problems this can fit

- Combine Excel or CSV exports that follow a defined structure; standardize column names, dates and number formats.
- Find duplicates, missing values or inconsistent entries using rules you can explain and review.
- Turn a recurring summary into a repeatable report, with agreed grouping rules and output columns.

## What to share first

Send a short description and a small, anonymized sample: remove or replace names, contact details and other sensitive values while keeping the relevant columns. Include the output you want, any calculation or matching rules, the approximate file size and how often the task repeats. Keep original files unchanged.

Mention your operating system and Excel version. The first email can describe the task without attaching files; a suitable sample and transfer method can be agreed afterwards.

## Possible deliverables

The agreed scope may include cleaned Excel / CSV files, a reusable workbook or script, and short instructions for running it again. Verification can cover row counts, agreed totals, duplicate handling and a list of entries that need your decision.

The output format and verification checks are agreed against your sample before work starts. A script is useful only if you can run it in the intended environment.

## Keep the first task bounded

Start with one defined workflow, known input formats and an example output. Confirm file sizes, rules, runtime environment and acceptance checks in writing. New input formats, additional reports, system integrations or ongoing operation require a separate scope discussion.

There is no fixed price or delivery promise on this page. A sample review determines whether the task can be accepted and what a quote should cover.

## One round of revision

The proposed scope includes one consolidated round of feedback against the agreed sample, rules and output. Send the changes together so they can be checked as a set. Additional requirements are discussed before extra work starts.
